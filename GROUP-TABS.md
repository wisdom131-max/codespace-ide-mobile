# Tabs: fresh source-only group audit

**State:** source reviewed; no device case has been run. `READ A/...:N` means 1-based line in `android/app/src/main/java/com/codespace/ide/`; `READ V/...:N` means 1-based line in checked-out `vscode-src/src/vs/`. Use a disposable project for all edits, closure and restart cases. This group owns primary editor tab lifetime, active selection, tab strip and menus, split **tab-based views**, tab/session recovery, and mirror handoffs. It does NOT claim a VS Code tiled editor-group grid: split here is another full-width strip entry for one shared file buffer. Project creation, Explorer tree, editing semantics, LSP transport and preview/browser tabs retain separate group owners.
