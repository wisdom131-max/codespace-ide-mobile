# Search: fresh source-only group audit

**State:** app and checked-out VS Code clone read; no device test run. `READ A/path:N` is 1-based in `android/app/src/main/java/com/codespace/ide/`, and `READ V/path:N` is 1-based in `vscode-src/src/vs/`. Search includes sidebar Find in Files/Replace, separate modal Go to File/Text/Replace, command palette file and symbol modes, workspace symbol index/LSP handoff, and search-to-tab navigation. Editor-local Find/Replace, chat attachment search and LSP implementation are *boundary checks*; their deeper implementations belong to other groups. All replacement tests require disposable files with independent copies and before/after byte comparisons. UI/source findings are not device outcomes or a code-fix authorization.
