# IntelliSense: fresh source-only group audit

**State:** app and checked-out VS Code clone read; no device test run. `READ A/path:N` is 1-based in `android/app/src/main/java/com/codespace/ide/`, and `READ V/path:N` is 1-based in `vscode-src/src/vs/`. IntelliSense here means the completion pipeline (local keyword/snippet/stdlib sources, LSP fetch, merge/rank, popup, accept paths), signature help, hover, path completions, completion history/MRU, ghost text and the lightbulb/AI-fix UI hooks. Editor-group rows E14/E16 already cover the editor-facing overlays at feature level; deep LSP server lifecycle belongs to the LSP group; AI continuation generation belongs to the AI group. Nothing in this document is a device outcome or a code-fix authorization.
